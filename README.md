# 🎵 Concert Venue Customer Revenue & Experience Analytics

A Power BI dashboard solution built to help venue management monitor 
customer revenue, spending patterns, satisfaction levels, and repeat 
visit behaviour.

## 📊 Dashboard Pages

| Page | Key Visuals |
|------|-------------|
| Revenue Analysis | KPI cards, stacked bar, donut, country bar |
| Customer Analysis | Age/gender breakdown, map, spend by segment |
| Experience Analysis | Satisfaction gauges, scatter plot, repeat vs first-time |
| Time Trends | Monthly revenue line, heatmap, satisfaction trend |

## 🗂️ Dataset Features
- 13 features including Age, Gender, Country, Seating Region
- Ticket, Merchandise, and Drink spend per customer
- Satisfaction Score and Recommendation Likelihood (0–10)
- Visit Date for time-series analysis

## 🛠️ Tools Used
- Power BI Desktop
- Power Query (data transformation)
- DAX (calculated measures)

## 📐 Data Model
- **Fact table:** FactSales (transactions)
- **Dimension tables:** DimCustomer, DimDate, DimRegion

## 🔍 Key Insights
- VIP segment drives highest revenue per customer (~$700 avg)
- Repeat visitors score satisfaction 1.3 pts higher than first-timers
- Summer months (Jun–Aug) generate peak revenue and visit volume
- USA, UK, and Australia are top revenue-contributing countries
